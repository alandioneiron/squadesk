# Visão do Produto

O Squadesk é um plugin de Claude Code. Ele mostra o Tech Lead e os subagentes trabalhando numa sala, cada um na mesa do seu papel. Tem também um painel web na rede local e uma skill que instala tudo em outras contas. É código aberto (MIT).

## Usuários e problema
- **Quem usa:** quem trabalha com o Claude Code delegando a subagentes, em projetos com várias frentes (código, testes, documentação).
- **Que problema resolve:** sem o Squadesk, não se vê quem está fazendo o quê, quanto custa, nem quando um agente espera aprovação. Também não há uma regra que leve o modelo principal a delegar ao modelo mais barato capaz.

## Objetivos
- Mostrar ao vivo cada agente na mesa certa, com atividade, tokens, tempo e pedidos de aprovação.
- Pôr no começo de cada conversa um guia de delegação para a equipe do projeto.
- Ver todos os chats da máquina num painel, no PC, no celular ou na TV.
- Instalar em qualquer conta com uma conversa guiada.

## Não-objetivos
- Mandar dados para a internet ou para serviços de terceiros.
- Controlar os agentes pelo painel: ele só mostra, e edita mesas só pelo próprio PC.
- Substituir o marketplace de plugins para outros fins.
