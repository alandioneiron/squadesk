# Roteiro

Os marcos correspondem às versões (SemVer) e, quando forem criados, aos milestones do GitHub. O status de cada item fica na issue; esta nota guarda a ordem e o raciocínio. O que cada versão trouxe está no [[Changelog]].

| Versão | Tema | Situação |
|---|---|---|
| 0.3.x | Sala no chat: tokens, cronômetro, aprovação, histórico, outros chats | Entregue |
| 0.4.x | Painel web (Lista, Mosaico, TV) e edição de mesas | Entregue |
| 0.5.x | Guia automático de delegação e skill de instalação | Entregue |
| 0.6.x | Squadesk código aberto, manual completo, fuso local | Entregue |
