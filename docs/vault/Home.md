# Squadesk · Sala dos Agentes

O Squadesk é um plugin de Claude Code. Ele mostra o Tech Lead e os subagentes trabalhando numa sala, cada um na mesa do seu papel. Tem também um painel web na rede local e uma skill que instala tudo em outras contas. É código aberto (MIT).

Este vault é a memória de quem **desenvolve** o projeto. Quem só quer instalar e usar lê o `README.md` e o `docs/MANUAL.md`.
